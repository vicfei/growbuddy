# WeKnora 二开上下文目录

本目录存储 AI 辅助开发所需的设计文档、数据库快照、提示词模板和进度记录。
- `design/`: 架构与数据模型设计
- `schema/`: 数据库表结构 DDL
- `prompts/`: 给 AI 工具的标准化指令
- `sessions/`: 会话切换时的状态存档
