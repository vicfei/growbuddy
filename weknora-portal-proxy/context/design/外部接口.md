# 外部接口契约

> 分两部分：① 本代理**消费**的 WeKnora API（全部零改动现成端点）；② 本代理**对外提供**的页面与 API。
> WeKnora 基础路径 `http://localhost:8080/api/v1`（env `WEKNORA_BASE_URL` 可调）。

## 一、消费 WeKnora：认证三件套（每个请求都要带）

| 头 | 值 | 说明 |
|---|---|---|
| `X-API-Key` | tenant key 明文 | 能力：retrieve + ingest + chat（不给 full access） |
| `X-Tenant-ID` | 公司租户 id | tenant key 与头必须一致（`auth.go:416-430` 不一致 403） |
| `X-External-User-Token` | 按**当前请求的员工**现签的 JWT | HS256(hmac_secret)；aud=`weknora`；exp=now+30min（≤24h 红线内取短）；claims=`sub`(=uum_user_id) + `tenant_id`(=公司租户)；约束依据 `verifyExternalUserJWT`（`auth.go:611-657`） |

> 签发实现要点：sub 须通过 `validateExternalUserID`（≤128、无控制字符）；同一员工的 token 不缓存超过 5 分钟（POC 直接每请求现签，成本可忽略）。
> 错误码速查：401 key 无效/外部 JWT 无效；403 跨租户/能力缺失；409 缺 X-Tenant-ID。

## 二、消费 WeKnora：端点清单（POC 所需）

| 用途 | 方法+路径 | 备注 |
|---|---|---|
| KB 全量列表 | `GET /knowledge-bases` | 单租户=公司全部 KB；**代理侧再按权限表过滤** |
| KB 详情 | `GET /knowledge-bases/:id` | |
| 检索 | `POST /knowledge-bases/:id/hybrid-search` | body 透传（query_text 等）；能力 retrieve |
| 建聊天会话 | `POST /sessions` | 会话归属=`api_external_user:{tid}:{sub}` 按人隔离 |
| 会话列表 | `GET /sessions` | 天然只返回当前员工的会话 |
| 问答（SSE） | `POST /knowledge-chat/:session_id` | `Accept: text/event-stream`；**逐 chunk Flush 透传**；body 里的 knowledge_base_ids 在转发前经权限裁决 |
| 上传文档 | `POST /knowledge-bases/:id/knowledge/file` | multipart 透传；能力 ingest；仅 permission=editor 可达 |
| 健康探测 | `GET /health`（无认证） | /healthz/weknora 用 |

## 三、本代理对外：页面

| 路径 | 页面 | 门禁 |
|---|---|---|
| `GET /sso/authorize?redirect_uri=` | SSO 模拟登录页 | 无 |
| `POST /sso/authorize` | 校验+发 code+302 | 无 |
| `GET /sso/callback?code=` | 换身份+建会话+302 首页 | 无（code 一次性 60s） |
| `GET /login` | 跳转 /sso/authorize（登录入口壳） | 无 |
| `POST /logout` | 清会话 | 登录态 |
| `GET /` | KB 列表（按 category 分组） | 登录态 |
| `GET /kb/:id` | KB 详情+检索+文档列表+上传 | 登录态+**权限裁决（无权限 404+审计 denied）** |
| `GET /chat` | 问答页（会话列表+对话区+KB 选择器） | 登录态 |
| `GET /admin` | 管理后台（授权/总览/审计） | 登录态+is_admin |

## 四、本代理对外：JSON API（页面 AJAX 用，兼作未来 Java 控制台参考）

| 方法+路径 | 语义 |
|---|---|
| `POST /chat/session` | 建会话（body: `{kb_ids:[...]}`，先裁决）→ `{session_id}` |
| `POST /chat/:session_id` | SSE 问答（body: `{query_text, kb_ids}`；kb_ids 裁决后转发） |
| `POST /kb/:id/search` | 检索（body 透传 hybrid-search 参数） |
| `GET /api/admin/employees?q=` | 员工搜索 |
| `GET /api/admin/kbs` | WeKnora 全量 KB 实时列表（不缓存） |
| `GET /api/admin/permissions?uum_user_id=&status=` | 授权总览（过期状态渲染时推断） |
| `POST /api/admin/permissions` | 授权/改权限（body: `{uum_user_id, kb_id, permission, category, valid_until?}`；upsert 语义） |
| `DELETE /api/admin/permissions/:id` | 回收（status=revoked） |
| `GET /api/admin/audit?actor=&action=` | 审计查询 |
| `GET /healthz` / `GET /healthz/weknora` | 自检 / 探测 WeKnora+key |

响应统一 `{success, data|error}`；错误 `{success:false, error:{code, message}}`（沿用 WeKnora 风格）。

## 五、SSE 转发契约（问答）

```
浏览器                    代理                          WeKnora
  │ POST /chat/:sid  ─────▶ 权限裁决 kb_ids ────────────▶ POST /knowledge-chat/:sid
  │                        (X-External-User-Token 按人)
  │ ◀──flush─ chunk ◀────── Flusher.Flush() 逐 chunk ◀──── SSE event: data: {...}
  │ ◀──flush─ ...          （不解析、不改写、不缓冲整包）
```

超时：代理侧读超时 300s（LLM 长回答兜底）；客户端断开→代理取消上游 Context，会话在 WeKnora 侧自然保留。

## 六、配置项（全 env，零配置文件）

| env | 说明 | 示例 |
|---|---|---|
| `PROXY_ADDR` | 监听地址 | `:8081` |
| `PORTAL_DB_DSN` | portal_proxy 库 DSN | `postgres://postgres:***@localhost:5432/portal_proxy?sslmode=disable` |
| `WEKNORA_BASE_URL` | WeKnora API 基址 | `http://localhost:8080/api/v1` |
| `WEKNORA_TENANT_ID` | 公司租户 id | `10010` |
| `WEKNORA_TENANT_KEY` | tenant key 明文 | （密钥管理，不进仓库） |
| `WEKNORA_HMAC_SECRET` | signed_token 密钥 | （同上；与租户配置一致） |
| `PORTAL_COOKIE_SECRET` | 会话 cookie 签名密钥 | 随机 32B |

> 密钥纪律（决策 021 同款）：明文只出现在 env/密钥管理系统；仓库内一律占位符。
