# 功能文档（POC 范围）

> 目标：一个能完整走通「登录→浏览→检索→问答→上传→管理」的模拟门户系统。
> 验收剧本与 v2 路线共用同一份（见 sessions/progress.md），保证两条路线可比。

## 模块一：SSO 模拟（模仿公司统一认证）

**形态**：OAuth 2.0 授权码流程的完整模仿，让"以后接真 SSO"只换 adapter 不动骨架。

| 步骤 | 端点 | 行为 |
|---|---|---|
| 1 | `GET /sso/authorize?redirect_uri=...` | 模拟 IdP 登录页：员工工号+密码表单（对 employees 表校验，bcrypt） |
| 2 | `POST /sso/authorize` | 校验通过 → 生成一次性 code（60s 有效）→ 302 回 redirect_uri?code= |
| 3 | `GET /sso/callback?code=` | 代理后端用 code 换身份——**响应只含 uum_user_id**（模拟"SSO 只返回 user_id"的新口径，不含部门/职位） |
| 4 | （代理内部） | 建门户会话 → 302 首页 |

- code 一次性、绑定 redirect_uri、60 秒过期（防重放）；
- 员工在 employees.is_active=false 时拒绝（模拟离职禁用）；
- 退出：`POST /logout` 清 cookie。

## 模块二：登录界面

极简登录页（实为 SSO 模拟页）：工号 + 密码 + 「单点登录」按钮；页脚标注"SSO 模拟环境"。
不做注册/找回（POC 员工由种子数据灌入）。

## 模块三：知识库浏览（终端用户视角）

| 页面 | 路径 | 内容 |
|---|---|---|
| 首页/KB 列表 | `GET /` | 按权限过滤后的 KB 卡片列表；**按 category 分组显示**（种子数据给"个人/团队/公共"三类标签，模拟空间分组观感）；卡片显示：名称、描述、文档数（WeKnora 统计）、我的权限（viewer/editor） |
| KB 详情+检索 | `GET /kb/:id` | KB 元信息 + 检索框 → `POST /kb/:id/search`（代理转发 hybrid-search，逐条结果再校验 KB 归属）+ 文档列表 |
| 上传 | `GET /kb/:id` 页内 | 仅 permission=editor 可见上传入口；multipart 转发 WeKnora `/knowledge/file` |

**权限裁决规则**（perm 引擎唯一入口）：
- 列表 = WeKnora 全量 KB ∩ kb_permissions(uum_user_id, status=active, valid_until 未过期)；
- 单 KB 访问（详情/检索/上传/聊天引用）= 逐请求查表，未命中一律 404（不泄露 KB 存在性）；
- editor 权限才可上传；viewer 只读。

## 模块四：问答界面（聊天）

| 项 | 设计 |
|---|---|
| 页面 | `GET /chat`：左侧会话列表（WeKnora 按 sub 隔离返回的历史）+ 右侧对话区 + KB 选择器（仅列有权限的 KB） |
| 发送 | `POST /chat/:session_id`：fetch 流式消费 SSE；**KB 选择参数在代理侧先经权限裁决再转发** |
| 转发 | 代理逐 chunk Flush 透传（架构设计.md 流 3）；代理不解析不改写内容 |
| 会话创建 | `POST /chat/session`：代理以按人 token 调 WeKnora `POST /sessions` |

## 模块五：后端管理（管理界面）

管理员（employees.is_admin=true）可见，入口 `GET /admin`：

| 页面 | 功能 |
|---|---|
| 授权管理 | 双栏：左=员工搜索列表；右=KB 列表（来自 WeKnora 全量）；点选建立/解除授权；每条授权可设 permission（viewer/editor）、valid_until（可空=永久）、category 标签 |
| 授权总览 | 全部授权行表格：员工/KB/权限/有效期/状态（active/expired/revoked），支持按员工筛选；过期行标红（ExpirySweep 由读取时惰性判定 + 每次启动/定时清理，POC 简化为读取时判断） |
| 审计查询 | audit_log 表格：时间/操作人/动作/对象/详情 JSON |
| KB 同步 | 「从 WeKnora 刷新 KB 列表」按钮（管理页直接实时拉，不落库缓存） |

管理 API（JSON，供页面 AJAX，也可独立给未来 Java 控制台参考）：
`GET/POST/DELETE /api/admin/permissions`、`GET /api/admin/audit`、`GET /api/admin/employees?q=`、`GET /api/admin/kbs`。

## 模块六：横切功能

- **审计**：所有授权变更与越权拦截写 audit_log（actor=操作人工号；越权事件 actor=被拦者，action=denied）；
- **越权测试钩子**：`GET /kb/:id` 对无权限用户返回 404 并记审计——验收剧本最后一项的依据；
- **健康检查**：`/healthz`（自身）+ `/healthz/weknora`（探测 WeKnora 可达与 key 有效性）；
- **配置**：全部 env（见架构设计），零配置文件，密钥不落盘。

## 明确不做（POC 边界）

组织架构/部门树、审批流、批量导入、消息通知、多因素认证、国际化、移动端适配、单元测试以外的 E2E 框架、真 SSO 对接（KIP 形态待调研回填，接口已按可替换设计）。
